BloodHound Legacy 4.3.1 with support for data collected by BloodHound Community Edition (CE). Use Legacy's readable graph layout on large environments while still seeing everything CE collects.

## What's new in 1.3.0

- **Node Info panels for AD CS**: EnterpriseCA, RootCA, AIACA, NTAuthStore, CertTemplate and IssuancePolicy nodes open their own panels instead of the generic CE Properties panel, following CE's panels. Enterprise, root and AIA CAs show their PKI hierarchy at the top (issued CAs, issuing chain, NTAuth store, domains). Enterprise CAs also show hosting computers, published templates and enrollment rights; templates show the CAs they're published to, issuance policies and enrollment rights; NTAuth stores show their trusted CAs; issuance policies show linked templates and their linked group. Every AD CS panel has Inbound Control Rights (explicit, unrolled, transitive) over the control edges CE uses, including ManageCA, ManageCertificates, Enroll and the PKI flag writes.
- **Panels for local groups and users**: ADLocalGroup and ADLocalUser show their computer, members or memberships, and logon rights.
- **More control sections**: Base nodes show inbound and outbound object control, Containers and OUs show inbound control rights, Azure devices show inbound object control, and Azure roles show their approvers.
- **Object type next to the name**: every Node Info panel's title reads "Name - Type", so you can see what kind of node is selected at a glance.
- **One Node Properties section**: each panel lists its usual fields first and then every other property the node has, so the separate Extra Properties and CE Properties sections are gone. Property names come from CE's own display names, which fixes labels like "Admin Is Trators".
- **Fix: high value diamond that wouldn't unmark**: **Unmark as High Value** now removes the diamond from any node, including ones CE marks as Tier Zero and protected-group members, and **Mark as High Value** brings it back. The menu shows Unmark whenever a node has the diamond. CE's `ProtectAdminGroups` edges no longer count as protected, because they also point at accounts that have left their admin groups, so former admins no longer get the diamond.

Full changes: [v1.2.0...v1.3.0](https://github.com/edtrud385/BloodHound-Legacy/compare/v1.2.0...v1.3.0)

## Everything this fork adds to Legacy 4.3.1

- **CE node icons**: every CE node kind uses CE's icon and colour, including the ADCS objects (EnterpriseCA, RootCA, AIACA, NTAuthStore, CertTemplate, IssuancePolicy) that Legacy drew as blank question marks, and the AD Sites kinds.
- **High value markers from CE**: nodes CE marks as Tier Zero (`Tag_Tier_Zero`, `admin_tier_0`) get the diamond. An optional setting also marks protected groups, their members and privileged Entra role holders. Display only; nothing is written to the database.
- **ADCS attack-path composition**: right-click an ADCS edge (ESC1, ESC3, ESC4, ESC6, ESC9, ESC10, ESC13, GoldenCert) and choose **Expand ADCS Composition**, or right-click a domain and choose **Expand ADCS Attack Paths**.
- **Help for CE edges**: every CE edge has Info and Refs tabs in its Help panel.
- **All properties in Node Info**: every node shows all of its properties, including the ones CE collects, with CE's readable names, including node kinds Legacy had no panel for.
- **PKI / AD CS and AD Sites counts** in the Database Info tab.
- **AD Sites and AD CS panels**: Node Info for Site, SiteServer, SiteSubnet and every AD CS kind, including who controls each object and the PKI hierarchy.
- **Edge filtering for every edge and every query**: filter the CE edges, and optionally apply the filter to prebuilt, custom and raw queries too.
- **Graph images**: a camera button saves the graph as a PNG with a configurable size, padding, markers and folder, including numbered auto-save.
- **Label settings**: keep labels visible at every zoom level and set their size.
- **Custom query categories**: a category dropdown filters your custom queries, grouped by platform (Active Directory / Entra ID).
- **About window**: shows the fork version and can check for a newer release, with a badge on the menu button when one exists. It never downloads or installs anything.

See the [README](https://github.com/edtrud385/BloodHound-Legacy#readme) for details and screenshots.

## First launch

These builds are not code-signed, so your OS will warn the first time:

- **Windows**: SmartScreen shows "Windows protected your PC". Click **More info**, then **Run anyway**.
- **macOS**: right-click `BloodHound.app` and choose **Open**, then **Open** again. If macOS says the app is damaged, run `xattr -cr /path/to/BloodHound.app` in Terminal and try again.
