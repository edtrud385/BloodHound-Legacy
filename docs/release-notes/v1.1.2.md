BloodHound Legacy 4.3.1 with support for data collected by BloodHound Community Edition (CE). Use Legacy's readable graph layout on large environments while still seeing everything CE collects.

## What's new in 1.1.2

Catches up with data from BloodHound CE 9.8, AzureHound v3.1 and SharpHound v2.17.

- **Explanations for more edges**: right-click an edge and choose **Help** to see what it means and what it lets a principal do, with a link to the BloodHound documentation. Now covers AZAuthenticatesTo, AZRoleEligible and AZRoleApprover (PIM), the NTLM relay edges (CoerceAndRelayNTLMToSMB, ToLDAP, ToLDAPS, ToADCS), WriteAltSecurityIdentities, WritePublicInformation and ServerIs. CE's AZKeyVaultContributor now opens the Key Vault Contributor explanation.
- **Fixed documentation links**: the Refs links in the CE edge Help panels pointed at pages that no longer exist on the BloodHound documentation site. They now open the right page.
- **Tier Zero nodes keep their icon**: nodes CE tags as Tier Zero (or Owned) sometimes drew as a black circle and opened a generic Node Info panel. They now show their normal icon and panel.
- **Pathfinding follows every edge in the database**: pathfinding and the prebuilt queries that use the edge filter used to skip edge types this build had not seen drawn yet, such as AZAuthenticatesTo. Every edge type in the database is now added to the edge filter on connect and after each upload.
- **New Edge Filtering sections**: **NTLM Relay** and **Entra ID (CE)**, plus the new AD edges under CE Attack Paths.
- **Federated identity credentials**: AZFederatedIdentityCredential nodes have their own Node Info panel showing the issuer, subject and audiences, the app they sign in as and that app's service principal.
- **AD Sites icons**: Site, SiteServer and SiteSubnet nodes get icons instead of blank question marks.
- **Key Vault counts**: the Key Vault Node Info controller counts now include CE's AZKeyVaultContributor edge.
- Fixed a misspelled default edge-filter entry (`AZLogicAppContributo`); it is removed from existing settings automatically.

Full changes: [v1.1.1...v1.1.2](https://github.com/edtrud385/BloodHound-Legacy/compare/v1.1.1...v1.1.2)

## Everything this fork adds to Legacy 4.3.1

- **CE node icons**: every CE node kind uses CE's icon and colour, including the ADCS objects (EnterpriseCA, RootCA, AIACA, NTAuthStore, CertTemplate, IssuancePolicy) that Legacy drew as blank question marks, and the AD Sites kinds.
- **High value markers from CE**: nodes CE marks as Tier Zero (`Tag_Tier_Zero`, `admin_tier_0`) get the diamond. An optional setting also marks protected groups, their members and privileged Entra role holders. Display only; nothing is written to the database.
- **ADCS attack-path composition**: right-click an ADCS edge (ESC1, ESC3, ESC4, ESC6, ESC9, ESC10, ESC13, GoldenCert) and choose **Expand ADCS Composition**, or right-click a domain and choose **Expand ADCS Attack Paths**.
- **Help for CE edges**: every CE edge has Info and Refs tabs in its Help panel.
- **CE Properties in Node Info**: every node shows all of its CE properties with readable names, including node kinds Legacy had no panel for.
- **PKI / AD CS counts** in the Database Info tab.
- **Edge filtering for every edge and every query**: filter the CE edges, and optionally apply the filter to prebuilt, custom and raw queries too.
- **Graph images**: a camera button saves the graph as a PNG with a configurable size, padding, markers and folder, including numbered auto-save.
- **Label settings**: keep labels visible at every zoom level and set their size.
- **Custom query categories**: a category dropdown filters your custom queries, grouped by platform (Active Directory / Entra ID).
- **About window**: shows the fork version and can check for a newer release. It never downloads or installs anything.

See the [README](https://github.com/edtrud385/BloodHound-Legacy#readme) for details and screenshots.

## First launch

These builds are not code-signed, so your OS will warn the first time:

- **Windows**: SmartScreen shows "Windows protected your PC". Click **More info**, then **Run anyway**.
- **macOS**: right-click `BloodHound.app` and choose **Open**, then **Open** again. If macOS says the app is damaged, run `xattr -cr /path/to/BloodHound.app` in Terminal and try again.
